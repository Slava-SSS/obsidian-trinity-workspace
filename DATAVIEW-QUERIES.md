# Dataview: Запросы для карточек заказов

## Вывести все заказы со статусом "в работе"

```dataview
table without id
  Статус as "Статус",
  Заказ as "Название",
  Описание as "Описание",
  Срок as "Срок"
from "Заказы"
where Статус = "в работе"
sort Срок asc
```

## Карточки по проектам (с группировкой)

```dataview
table without id
  Проект,
  Название,
  Статус,
  Срок
from "Проекты"
group by Статус
sort Срок desc
```

## Следующие действия (Dataview + Tasks)

```dataview
task from "Задачи"
where !completed
and due <= 2026-10-03
sort due asc
```

## Заказы: таблица с фильтром по дате

```dataview
table without id
  Статус,
  Заказ,
  Срок
from "Заказы"
where Срок >= date(2026-10-01) and Срок <= date(2026-10-10)
sort Срок asc
```

## Вывести СЧЁТЧИК заказов в работе

```dataview
LIST length(rows) as "Заказов в работе"
from "Заказы"
where Статус = "в работе"
```

## Карточки через LIST (для более гибкого вывода)

```dataview
list WITHOUT id
  "**" + Заказ + "** - " + Описание + " (📅 " + Срок + ")"
from "Заказы"
where Статус = "в работе"
sort Срок asc
```

## Синтаксис фильтров

- `=` точное совпадение
- `!=` не равно
- `>` больше
- `<` меньше
- `>=` больше или равно
- `<=` меньше или равно
- `contains` содержит текст
- `AND` логическое И
- `OR` логическое ИЛИ

## Форматирование таблиц

- `table` — таблица с ID и файлом
- `table without id` — таблица без ID
- `list` — список
- `LIST` — список с кастомным форматом
