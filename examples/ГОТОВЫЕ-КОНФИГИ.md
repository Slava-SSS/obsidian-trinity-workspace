# Готовые конфигурационные файлы

## appearance.json
Для `.obsidian/appearance.json`

```json
{
  "theme": "obsidian",
  "accentColor": "#d4fb72",
  "translucency": false,
  "cssEnabledSnippets": [
    "design",
    "главная"
  ]
}
```

**Что это делает:**
- Устанавливает тему Obsidian
- Акцент цвет: лайм (#d4fb72)
- Включает CSS сниппеты
